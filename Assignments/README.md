# Assignments

Three individual assignments for STAT3612 Statistical Machine Learning.

| Notebook | Topics | Dataset |
|----------|--------|---------|
| `Logistic_Regression_Employee_Attrition.ipynb` | Logistic regression, regularization | Employee attrition |
| `DecisionTree_PCA_SVM_HeartDisease.ipynb` | Decision tree, PCA, SVM | Heart disease |
| `LDA_Softmax_MNIST.ipynb` | Linear Discriminant Analysis, softmax classifier | MNIST |

Datasets are stored in `data/`.
