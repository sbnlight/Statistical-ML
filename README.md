# Statistical-ML

STAT3612 Statistical Machine Learning — The University of Hong Kong.

## Contents

| Folder | Description |
|--------|-------------|
| `Assignments/` | Three notebook assignments covering classical ML: logistic regression, decision trees, PCA, SVM, LDA, softmax regression |
| `GroupProject/` | Group project: ensemble models for hospital readmission prediction (notebook + final report) |

See each subfolder's README for details.

## Setup

Notebooks use Python 3 with `scikit-learn`, `pandas`, `numpy`, `matplotlib`, and `pytorch`.

```bash
pip install scikit-learn pandas numpy matplotlib torch
```

Open notebooks in JupyterLab or VS Code.
